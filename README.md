# GitHub 默认开发规范

这个仓库用于维护个人 GitHub 项目的默认社区健康文件（Community Health Files）。

当其他仓库没有定义自己的对应文件时，可以默认使用这里的 Issue 模板、Pull Request 模板和贡献规范。

当前包含：

- Bug Issue 模板
- 功能需求 Issue 模板
- 重构 Issue 模板
- Pull Request 模板
- `CONTRIBUTING.md` 通用贡献规范

## 使用原则

这里仅维护跨项目通用的开发规范，例如：

- Issue 驱动开发
- 分支命名规范
- Conventional Commits
- Pull Request 基本要求
- CI 通过后再合并

具体项目的分支模型、稳定分支、开发分支、PR 目标分支和发布流程，应由项目自己的 `CONTRIBUTING.md` 定义。

推荐的通用开发闭环：

`Issue → Branch → Commit → Pull Request → CI → Merge → Close Issue`

具体规则请查看 `CONTRIBUTING.md`。
